Eine Übermittlung in die USA ist dabei nicht ausgeschlossen; die Google LLC ist nach dem EU-U.S. Data Privacy Framework zertifiziert, für das ein Angemessenheits­beschluss der EU-Kommission gilt. Für die endgültige Website werden die Schriften auf dem eigenen Server liegen. Dann gelangen beim Laden der Schriften keine Daten mehr an Google.
